# The Story Behind the Statute

Replication code and data for **"The Story Behind the Statute: Congressional Witnesses as Narrative Agents and Storytellers"** by Collin A. Coil, Caroline L. Bruckner, John D. Rackey, and Lauren C. Bell.

The study uses the opening statements of 5,612 witnesses who testified at 1,592 hearings before 37 House and Senate standing committees during the 118th Congress (2023–2024). Each witness is hand-labeled as a *storyteller* (their testimony contains a narrative) or a *non-storyteller*. The code reproduces every figure and table in the paper.

## Repository layout

```
Code/       Analysis scripts (Python and R)
Data/       Input data and intermediate outputs
Results/    Figures that appear in the paper
```

## Setup

### Python (uv)

The Python environment is managed with [uv](https://docs.astral.sh/uv/). Install uv, then run from the repository root:

```bash
uv sync
```

This creates `.venv/` with Python 3.11 and the exact package versions in `uv.lock`. On Windows and Linux, PyTorch is installed from the CUDA 11.8 wheel index. That build also runs on machines without a GPU.

Run every script from the repository root so the relative `Data/` and `Results/` paths resolve:

```bash
uv run python Code/<script>.py
```

> **Tip:** If the repository sits in a synced folder (OneDrive, Dropbox, iCloud), put the environment elsewhere so the multi-gigabyte PyTorch install is not synced. For example, set `UV_PROJECT_ENVIRONMENT=~/.venvs/congressional-storyteller` before running `uv sync` and `uv run`.

The first run of some scripts downloads models and corpora: NLTK stopwords/WordNet/Punkt, the Stanza English model, and `Qwen/Qwen3-Embedding-4B` from Hugging Face (about 8 GB).

### R

The regressions were run with R 4.2.3. Install the required packages with:

```bash
Rscript Code/install_r_packages.R
```

Package versions used for the paper: `readxl` 1.4.3, `lme4` 1.1-35.3, `lmerTest` 3.1-3, `performance` 0.15.1.

## Reproducing the paper

Each step reads from `Data/` and writes to `Data/` or `Results/`. Steps 1–3 depend only on `Data/testimonies.xlsx` and can run in any order. Step 5 needs the output of step 4, which is already included in `Data/`.

| Step | Command | Produces | Paper |
|---|---|---|---|
| 1 | `uv run python Code/descriptive_stats.py` | Printed descriptive statistics; `Results/Storytellers by Occupation.png`, `Results/Storytellers by Committee.png` | Gender, occupation, and committee statistics; Figures 1–2 |
| 2 | `uv run python Code/prep_data_for_allotax.py` | `Data/Storyteller_unigrams.json`, `Data/Non-Storyteller_unigrams.json` | Input to Figure 3 (see below) |
| 3 | `uv run python Code/topic_modeling.py` | `Results/optimal_number_topics.png`, `Results/permutation_test_jsd.png`, `Results/topic_wise_jsd.png`, `Results/topic_probabilities.png`; topics and JSD printed | Figures 4–7 |
| 4 | `uv run python Code/information_content.py` | `Data/witness_testimony_content.xlsx`, `Data/hearing_testimony_content.xlsx` | Information content scores |
| 5 | `Rscript Code/information_content_regressions.R` | Model summaries, ICC, and R² printed; diagnostic plots | Tables 4–5 |

### Notes on individual steps

- **Figure 3 (allotaxonograph).** `prep_data_for_allotax.py` writes word counts and probabilities for each group in the JSON format the [Allotaxonometer](https://doi.org/10.1140/epjds/s13688-023-00400-x) (Dodds et al. 2023) reads. The figure in `Results/storyteller_allotaxs/` was generated by the Allotaxonometer from these two files, using rank-turbulence divergence with α = 0.17.
- **Topic modeling.** NMF uses a fixed `random_state` (2025), so the coherence scores, topics, and observed Jensen–Shannon divergence are deterministic. The bootstrap confidence intervals and the permutation test use unseeded random draws, so those values vary slightly from run to run.
- **Information content.** Sentence embeddings come from `Qwen/Qwen3-Embedding-4B`, which needs a GPU with roughly 16 GB of memory to run in reasonable time. Embedding all 5,612 statements takes several hours. The outputs used in the paper are included in `Data/`, so step 5 can be run without repeating step 4.
- **Regressions.** The R script also draws residual and random-effect QQ plots to check model assumptions. With `Rscript`, they are saved to `Rplots.pdf`.

## Data

All data needed to reproduce the analyses are in `Data/`.

### `testimonies.xlsx` — primary dataset (one row per witness)

Compiled by the authors from official hearing transcripts published by the Government Publishing Office. Statements were lightly cleaned to remove interruptions and boilerplate opening and closing sentences. Witnesses were hand-labeled as storytellers following the coding rules described in the paper.

| Column | Description |
|---|---|
| `Statement` | Cleaned text of the witness's opening statement |
| `Witness` | Witness name |
| `Gender` | 0 = man, 1 = woman, 2 = transgender, non-binary, or gender not identifiable |
| `Hearing` | Hearing title |
| `Congress` | Congress number (118 for all rows) |
| `Date` | Hearing date |
| `Branch` | Chamber: `House` or `Senate` |
| `Committee` | Full committee name |
| `Subcommittee` | Subcommittee name, blank for full-committee hearings |
| `Panel Type` | Gender makeup of the witness panel: `Manel` (all men), `Womanel` (all women), or `Mixed` |
| `Occupation` | Witness occupation category. `SLTT` = state, local, tribal, or territorial government |
| `Party Control` | Majority party of the chamber: 0 = Republican (House), 1 = Democratic (Senate) |
| `Narrative` | 1 = storyteller, 0 = non-storyteller |
| `Hearing_Type` | `legislative`, `oversight`, `investigative`, or `budgetary` |

### Derived files

| File | Created by | Contents |
|---|---|---|
| `Storyteller_unigrams.json`, `Non-Storyteller_unigrams.json` | `prep_data_for_allotax.py` | One record per word: `types` (word), `counts`, `totalunique` (vocabulary size), and `probs` (relative frequency) |
| `witness_testimony_content.xlsx` | `information_content.py` | `testimonies.xlsx` plus `Info_Content`, the testimony-level information content score |
| `hearing_testimony_content.xlsx` | `information_content.py` | One row per hearing: `Num_Witnesses`, `Num_Women`, `Occupations` (count of each occupation), `Num_Narratives`, `Info_Content` (hearing-level score), `Percent_Women`, `Herfindahl_Index` (occupational concentration), `Percent_Narratives`, and the hearing identifiers |
